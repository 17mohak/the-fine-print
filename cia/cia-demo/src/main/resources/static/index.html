The Fine Print · Evidence Integrity Lab

Does the document really say that?

Check a claimed quotation against its source in one pass. First, exact matching establishes whether and where the quotation occurs. Then the clause it sits in is screened against a library of reference clause wordings, and every possible hit is compared exactly. The result says plainly what is verified, what is screened, and what this check cannot tell you.

Synthetic data only. Every result is computed by the Java backend (/algo/*); nothing is precomputed in the browser.

        How KMP ran: the prefix function

        π[i] is the length of the longest proper prefix of the quote that is also a suffix of its first i + 1 symbols. On a mismatch, KMP falls back to π instead of re-reading the text, so each text symbol is compared a bounded number of times.
